# AGENTS.md

- Everything committed to this repo is written in English: code, comments, docs, commit messages, and test data too (names of phones and people, router pages in fixtures and tests).
- This repo is public: NEVER commit personal data. No real router address, host name or credentials, no real MAC or IP address, no real phone or person names, and no recording from a real router (status pages, logs) unless every address, name and identifier in it has been replaced with made-up ones. Test data uses made-up names and addresses (Alice's phone, Bob's phone, `02:00:00:00:00:01`, `192.168.1.1` is fine as a documentation address, `router.example`).
- This module is the `ddwrt` type of Bridge of [Oiko](https://github.com/llehouerou/oiko): it tells which configured phones are associated with a DD-WRT access point, for Oiko's Presence sources. It imports only Oiko's public `bridge` packages (`bridge`, `bridge/store`, `bridge/bridgetest`; Oiko's ADR 0017) and speaks Oiko's vocabulary (its `GLOSSARY.md`): Bridge, Device, Function, Capability, Native Address, Availability, Replay. Oiko's ADR 0050 is this type's design: read it before changing anything it decides.
- It follows the shape of Oiko's reference types (`docs/write-a-bridge.md`, and `oiko-netatmo`): one root package registering the type, `oiko-bridge.json` kept in step with the configuration by a test, tests through `bridgetest` inside `synctest.Test` with the router faked in memory behind an `http.RoundTripper` (no real clock or network), `go vet` and `gofmt` clean, no CI. Each Oiko minor release ends with this repo moved to it and tagged. The README keeps the plug README's shape.
- Releases follow Oiko's ADR 0019 as it applies to a type of Bridge: during v0, a patch neither breaks nor adds anything (configuration keys, Functions, Capabilities), a minor may break the configuration and its release notes list each change. Raising the required Oiko to a new minor is a minor here too. Releases are tags `vX.Y.Z` on `main`, after `go test ./...` passes. Apache-2.0: `LICENSE` and `NOTICE`, no per-file headers.
- Issues live in GitHub Issues (llehouerou/oiko-ddwrt), via `gh`.
