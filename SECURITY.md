# Security policy

oiko-ddwrt follows [Oiko's security policy](https://github.com/llehouerou/oiko/blob/main/SECURITY.md),
which covers every repository of its ecosystem: supported versions, what to expect, scope and
disclosure.

Report a vulnerability in this type of Bridge privately, through this repository's
[private vulnerability reporting](https://github.com/llehouerou/oiko-ddwrt/security/advisories/new),
never in a public issue.
